# GlobalNav Template Usage

This project uses `zendesk-globalnav-template` with a custom Admin Center API configuration page.

## Running

```bash
npm run dev
```

## What's included

- Prototype header (title, Started Sept 2026, Updated build date, Comment control)
- Prototype comments (Supabase via `.env.local`, project `incremental-api-blocking`)
- Admin Center chrome + Apps and integrations subnav
- API configuration settings + Incremental API partner extensions (progressive disclosure, table, Add partners modal, success toast)
